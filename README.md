# Word List Audio

English word list pronunciation audio collection, containing **3,489** MP3 files organized across **7 Word Lists** (35 Units in total, ~58 MB).

## Directory Structure

```text
.
├── Word List 1/
│   ├── Unit 1/
│   ├── Unit 2/
│   ├── Unit 3/
│   ├── Unit 4/
│   └── Unit 5/
├── Word List 2/
│   └── ...
├── ...
└── Word List 7/
    └── ...
```

Each audio file follows the `<index>_<word>.mp3` naming convention (e.g., `001_rehabilitation.mp3`, `010_abrupt.mp3`).
