---

## 🎯 适用场景 (Use Cases)

- **雅思词汇跟读（Shadowing）**：逐词跟读模仿重音、连读与元音发音，矫正中式发音习惯。
- **听力精听与听写（Dictation）**：按 Unit 进行盲听拼写自测，强化雅思听力 Section 1–4 常见词汇反应速度。
- **口语词汇激活（Speaking Activation）**：通过高频语音输入与大声跟读，将“认识的词”转化为“能脱口而出的词”。
- **工具与制卡素材（Anki / Web Player）**：标准化文件名与目录结构，可直接导入 Anki 记忆卡片或接入本地跟读播放器使用。

---

## 🎧 推荐跟读训练法 (Shadowing Practice Guide)

1. **盲听预热**：以 Unit 为单位（约 100 词），不看拼写先听一遍，标记反应不过来的词。
2. **延迟跟读（Shadowing）**：播放音频后间隔半拍大声跟读，重点模仿词重音（Word Stress）与尾音清晰度。
3. **录音对比**：录下自己的跟读音频并与原声对比，针对发音偏差词单曲循环强化。
4. **滚动复盘**：每完成一个 Word List（5 个 Unit）进行一次听写或快速过音复习。
